# Ascent Control code review snapshot

See the [README](../README.md) for the executable modules, offline commands and test instructions. This repository currently provides protocol parsers/encoders, firmware version comparisons, coordinate conversion, tile-header validation and dependency contracts.

The full desktop application and MSI are not included. The operator reports Caddx verbal approval for CRSF/MSP; Service Mode and dependent widget releases remain gated. See [source review](SOURCE_REVIEW.md) for provenance and [current status](STATUS.md) for migration limits.
