# Ascent Control developer preview announcement

Public progress announcement, 2026-11-06. Broader source publication and final licensing remain under review. This announcement does not grant software permissions.

We’re sharing an early look at Ascent Control, a community project for working with the Caddx Ascent ecosystem.

The public repository currently contains the foundation for application and widget package compatibility, dependency checks and upgrade planning, together with tests and a development workflow. The existing desktop application is still being migrated; this preview is for developers interested in reviewing the foundation and following its progress. A broader source import is under review.

Start here: https://github.com/TelaMechanica/ascent-control

Our intended source-available terms permit personal, hobbyist development, educational and private professional use with attribution, while prohibiting resale and reuse in third-party products. Final permissions will be stated in the repository license; they do not cover Caddx firmware or other third-party material. Check the current licensing status before using or redistributing code.

Ascent Control+ remains private pending Caddx guidance. There is no new public Windows installer in this preview. We’ll announce a downloadable build after the public source, licensing, packaging and installation checks are complete.

We welcome feedback on the proposed interfaces, compatibility rules and documentation. Contribution terms will be clarified alongside the license before accepting new code submissions.
